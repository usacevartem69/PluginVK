# Описание функций 

В этом документе описаны все функции, реализованные в этом проекте.

## Функция activate
Запускает плагин.

## Функция OpenVkCommand
Открывет браузер и страницу ВК и выводит сообщение об этом в окне.
+ переходит по ссылке "https://vk.com"

## Функция CreatePostCommand
Заполняет текстовый файл готовым шаблоном, который можно изменять.
+ Если он не открыт, то выводит сообщение об ошибке

## Функция OpenVkWithTextCommand
Открывает ВК в бразуре и сохраняет в буфер обмена текст файла, который был открыт в VS Code.
+ Сохраняет в буфер выделенный текст
+ Если файл пуст, то выводит сообщение об ошибке

## Функция deactivate
Завершает работу нашего плагина
